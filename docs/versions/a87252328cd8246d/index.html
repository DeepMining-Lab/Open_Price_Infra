Open Prices: data version a87252328cd8246d

Version of the Ethereum price datasets evaluated in the OpenPrice article (2 November 2026): 31 CSV files, 31 793 049 data lines (31 792 939 rows once the 110 duplicated swap events of the ETH/USDC file are removed).

The CSV files of the public folder are living files: new rows are appended every day and existing rows are never rewritten. Each file of this version is therefore the beginning of the current file.

  • inventaire_version_a87252328cd8246d.csv: for each file, the number of bytes of this version, their SHA-256 and the number of rows
  • manifeste_store_v3_a87252328cd8246d.json: the manifest the API published for this version (GET /v3/datasets/versions/a87252328cd8246d)
  • inventaire_store_v3.csv: file versions, quality counters, pool and feed addresses
  • table_des_phases_chainlink.csv: the block at which each Chainlink proxy moved to each aggregator phase
