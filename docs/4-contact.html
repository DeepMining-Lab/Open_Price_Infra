Contact

Questions about the datasets or the API, feedback, or a test API key for the Open Price Explorer: send us a message and we will answer you by email.

Test API keys

The Open Price Explorer queries the OpenPrice API through the DeepMining gateway, which requires an API key. During the test phase, keys are given on request:

  • Choose “Request a test API key” as the subject
  • Give your project name and how you plan to use the API
  • We answer by email
